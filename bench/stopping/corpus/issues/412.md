# Issue #412: Document the maximum partitions per topic

Status: open (opened 2026-07-01)

Users ask how many partitions a topic can have. We have not benchmarked large partition
counts yet. The code does not enforce a hard limit, but memory use grows with partition
count and nothing above 2,000 partitions has been tested by the team.
