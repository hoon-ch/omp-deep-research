# Kestrel 2.3.0 release notes

Released 2026-08-20.

## Highlights

- **lz4 by default.** New topics now use `compression.codec = lz4` unless a codec is set
  explicitly. Benchmarks showed 2.1x smaller segments with negligible CPU overhead.
- **Per-topic retention.** `kestrel topic alter --retention-hours` overrides the broker default.

## Upgrade notes

Existing topics keep their codec. To keep the previous behaviour for new topics, set
`compression.codec = none`.
