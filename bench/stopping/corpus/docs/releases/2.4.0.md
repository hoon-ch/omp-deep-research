# Kestrel 2.4.0 release notes

Released 2026-09-15.

## Highlights

- **zstd support.** `compression.codec = zstd` is now accepted. It is opt-in; new topics
  still default to the codec introduced in the previous release.
- **Cluster drain.** `kestrel cluster drain <broker>` moves leadership away before maintenance.

## Changed defaults

- `consumer.session_timeout_ms`: 30000 → 10000.
